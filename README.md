# RAFTAR

**Travel. Live. Relive.**

RAFTAR is a premium Northeast India travel, photography and filmmaking experience brand. We design journeys, capture them through professional photography and film, and deliver each customer’s memories through a private gallery.

## Current build

- Cinematic public website built with Next.js, TypeScript and Tailwind CSS
- Travel experiences: Solo Story, Friends Forever, Couple Chronicles and Wild Frames
- Photography and filmmaking storytelling sections
- Private gallery access route at `/gallery`
- Media-domain contracts in `types/media.ts` for the forthcoming Media Studio, media delivery and consent workflows

## Planned product modules

- Enquiry-first trip planning and booking confirmation
- Authentication and secure private media galleries
- Admin dashboard and configurable package media deliverables
- Media Studio for projects, crew assignment, editing workflow, delivery and customer publication consent
